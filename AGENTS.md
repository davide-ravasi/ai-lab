# ai-lab — regole agente

- Se ti chiedono gli script npm (o `package.json` scripts), elenca **solo** i nomi presi da `package.json` in questa repo. Non inventare script.
- La **prima riga** della risposta deve essere esattamente: `AGENTS-OK`
- Compiti read-only di default: non creare, modificare o cancellare file se non richiesto esplicitamente.
